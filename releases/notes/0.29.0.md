## 新功能
- 新增 Ping Island、macOS 与 Pixel 三套完整体验主题，并支持 Pixel 调色板切换
- 新增语义化会话音效与确认操作样式，让审批、完成、错误和用量状态在不同主题下保持一致反馈
- 独立悬浮宠物支持通过滑块自定义 `1×` 到 `10×` 尺寸

## 改进
- 放大悬浮宠物时，顶部用量图标和右下会话数字同步放大，同时保持固定贴边间距
- 设置窗口统一使用原生标题栏拖动，交互控件不再被内容区拖窗抢占手势
- 远程 SSH 主机可将 Codex 用量快照转发到本地 Ping Island，并按最新采集时间选择账户用量
- Claude 系列会话优先显示客户端写入的最新 `custom-title`，旧 transcript 仍兼容 summary 与首条消息回退
- 统一 Qoder CN IDE 与 CLI 的产品命名、图标和启动识别

## 修复
- 修复设置页拖动尺寸滑块时整个窗口被移动、滑块无法调整的问题
- 修复设置窗口主题背景重复叠加、标题栏与内容区出现色差或接缝的问题
- 保持屏幕顶部 Island 的黑色表面与经典动效不受体验主题切换影响

## New
- Adds complete Ping Island, macOS, and Pixel experience themes, including selectable Pixel palettes
- Adds semantic session sounds and confirmation-action styling so approvals, completions, errors, and usage states keep consistent feedback across themes
- Lets the detached floating pet use a custom size from `1x` to `10x` through a slider

## Improvements
- Scales the usage bolt and active-session number with enlarged floating pets while preserving fixed edge spacing
- Reserves Settings window movement for the native titlebar so interactive controls retain their pointer gestures
- Forwards Codex usage snapshots from remote SSH hosts and selects the newest captured account-wide usage
- Prefers the latest Claude-family `custom-title` while retaining summary and first-message fallbacks for older transcripts
- Aligns Qoder CN IDE and CLI product naming, icons, and launch recognition

## Fixes
- Fixes dragging the mascot-size slider moving the entire Settings window instead of adjusting the value
- Removes stacked Settings materials that caused titlebar/body color seams and inconsistent translucent backgrounds
- Keeps the screen-attached Island on its canonical black surface and motion treatment across experience themes

## Notes
- The Sparkle build number is now `77`, and the app version is now `0.29.0`
- Production artifacts are Developer ID signed and Apple-notarized through GitHub Actions
